Task Management App — Frontend

A modern and responsive Task Management App frontend built with React + Vite.

🚀 Features

- User Registration
- User Login
- JWT-based authentication
- Protected Dashboard
- Create Tasks
- View Tasks
- Update Tasks
- Delete Tasks
- Search Tasks
- Filter Tasks
- Responsive user interface

🛠️ Tech Stack

- React.js
- Vite
- JavaScript
- HTML5
- CSS3

📁 Project Structure

Frontend/
├── src/
├── public/
├── package.json
├── package-lock.json
└── README.md

⚙️ Installation

Clone the repository and open the Frontend folder:

cd Frontend
npm install

▶️ Run the Project

Start the development server:

npm run dev

Then open the local URL shown in the terminal.

🔗 Backend

The frontend communicates with the backend REST APIs for:

- Authentication
- Task creation
- Task retrieval
- Task updating
- Task deletion

📌 Project Status

Frontend development and task CRUD functionality are completed and tested with the backend APIs.
